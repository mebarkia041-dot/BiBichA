# 💜 BiBichA — بيبيشا

**بيبيشا شخصية ذكاء اصطناعي ترافق المستخدم**: تتحدث معه طبيعياً، تفهم سياق كلامه، تتذكر ما يأذن بحفظه، وتساعده كمساعد هاتف. هي ذكاء اصطناعي واضح وليست إنسانة، وليست مجرد صفحة دردشة.

## الحالة الحقيقية الآن

المستودع يجمع بين:
- نموذج ويب تجريبي قديم للمحادثة.
- Cloudflare Worker وسيط لواجهة OpenAI Responses API، لكنه غير منشور/غير مربوط بمفتاح فعّال حسب آخر تحقق.
- مشروع Android أصلي بلغة Kotlin: إعداد رابط Worker ورمز Android، حفظ الرمز مشفّراً عبر Android Keystore، أوامر صوتية أولية، ردود صوتية، وفتح تطبيقات والكاميرا.
- اتصال Android بخدمة الذكاء عبر Bearer token منفصل؛ مفتاح OpenAI يبقى في Cloudflare.
- سجل آخر 12 رسالة مشفّر محلياً مع زر لمسحه.
- قارئ اختياري لإشعارات تطبيقات المراسلة بعد موافقة المستخدم، مع تجنّب النطق على شاشة القفل وتجاهل إشعارات رموز التحقق.
- شاشة لطلب تعيين بيبيشا كمساعد النظام وإدارة صلاحيات الإشعارات.
- GitHub Actions لاختبارات الخادم وبناء APK تجريبي.

**مهم:** هذه وظائف أولية في الكود وليست نسخة هاتف مجرّبة. لا تعمل محادثة الذكاء من Android حتى تنشر Worker وتضبط الأسرار `OPENAI_API_KEY` و`MOBILE_APP_TOKEN` و`ALLOWED_ORIGIN`، ثم تدخل رابط Worker ورمز الهاتف في التطبيق. قارئ الإشعارات يحتاج موافقة صريحة. لا يوجد بعد إرسال رسائل تلقائي أو معرفة متصل مؤكدة أو إرسال موقع طوارئ.

## شخصية بيبيشا

- حنونة وذكية وخفيفة الظل، وتتحدث بالدارجة الجزائرية الطبيعية.
- ترافق المستخدم دون ادعاء أنها إنسانة أو تشجيع التعلق الحصري بها.
- لا تختلق ذكريات أو معلومات ولا تدعي تنفيذ أوامر الهاتف دون تأكيد.
- تحفظ فقط المعلومات التي يختار المستخدم حفظها، مع إمكانية عرضها وحذفها وتصديرها.

## ما ينقص قبل نسخة حقيقية مكتملة

1. بناء APK والتحقق من تثبيته وتشغيله على Oppo.
2. نجاح بناء APK وإصلاح أخطاء التجميع إن ظهرت.
3. اختبار جلسة الصوت والمساعد الافتراضي على Oppo.
4. نشر Worker وضبط أسرار `OPENAI_API_KEY` و`MOBILE_APP_TOKEN` و`ALLOWED_ORIGIN`.
5. إدخال رابط Worker ورمز الهاتف واختبار محادثة OpenAI حقيقية.
6. تطوير ذاكرة طويلة الأمد لحقائق يختار المستخدم حفظها.
7. إضافة إرسال الرسائل بواجهة تأكيد، والتعرف على المتصل، ومشاركة موقع الطوارئ بعد إعداد جهات الاتصال والصلاحيات.
8. اختبار الأذونات والبطارية والخصوصية، ثم إصدار APK موقّع.


لا نعلن عن أي ميزة مكتملة إلا بعد بناء واختبار يمكن التحقق منه.
