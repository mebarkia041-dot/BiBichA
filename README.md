# 💜 BiBichA — بيبيشا

مساعد شخصي بواجهة عربية ودارجة جزائرية، مصمم ليعمل كتطبيق ويب قابل للتثبيت على الهاتف.

## الموجود في النسخة الحالية
- واجهة محادثة عربية RTL.
- حفظ سجل المحادثة محلياً على الهاتف.
- ذاكرة شخصية محلية: اكتب **احفظ ...** أو **تذكر ...** لحفظ معلومة، واستعمل زر **الذاكرة** لعرضها أو مسحها.
- تصدير نسخة احتياطية من المحادثة والذاكرة إلى ملف JSON، واسترجاعها على الهاتف أو جهاز آخر.
- قراءة الردود صوتياً، مع خيار تشغيل الصوت التلقائي.
- إدخال صوتي عبر ميكروفون المتصفح إذا كان مدعوماً ومسموحاً.
- PWA مع تخزين ملفات الواجهة للعمل عند انقطاع الإنترنت.

## فحص الجودة
- توجد اختبارات تلقائية لخادم الذكاء الاصطناعي تشمل فحص الصحة، والتحقق من المصدر، وحجم الطلب، وسلامة تمرير المحادثة والذاكرة.
- تُشغّل الاختبارات تلقائياً عند كل تحديث للمشروع عبر GitHub Actions.

## ما يحتاج إعداداً قبل أن يعمل
**الذكاء الاصطناعي الحقيقي عبر الإنترنت غير مفعّل حتى الآن** إلى أن يتم نشر Cloudflare Worker وإضافة سر `OPENAI_API_KEY` في إعدادات Cloudflare، ثم وضع عنوان `/chat` في `api-config.js`. اتبع الخطوات المصورة نصياً في [دليل إعداد الخادم](worker/README.md).

## حدود مهمة
- دون إعداد الخادم، الردود تجريبية وليست ذكاءً اصطناعياً حقيقياً.
- دون إنترنت، تبقى الواجهة والبيانات المحلية متاحة، لكن خدمة الذكاء الاصطناعي عبر الإنترنت لا تعمل.
- الصوت يعتمد على دعم المتصفح والأصوات المثبتة في الهاتف؛ قد لا يتوفر صوت عربي جزائري على كل الأجهزة.
- الذاكرة الحالية محفوظة على نفس الهاتف والمتصفح، وليست مزامنة بين الأجهزة أو نسخة احتياطية سحابية.
- التطبيق لا يستطيع التحكم بحرية في الهاتف أو تجاوز قفله أو العمل كخدمة صوتية دائمة في الخلفية.
