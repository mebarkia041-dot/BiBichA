# 💜 Emilia — إميليا

**إميليا شخصية ذكاء اصطناعي ترافق المستخدم**: تتحدث معه طبيعياً، تفهم سياق كلامه، تتذكر ما يأذن بحفظه، وتساعده كمساعد هاتف. هي ذكاء اصطناعي واضح وليست إنسانة، وليست مجرد صفحة دردشة.

## الحالة الحقيقية الآن

المستودع يجمع بين:
- نموذج ويب تجريبي قديم للمحادثة.
- Cloudflare Worker اختياري فقط؛ التشغيل الأساسي لا يحتاج OpenAI API ولا بطاقة بنكية.
- مشروع Android أصلي بلغة Kotlin: إعداد رابط Worker ورمز Android، حفظ الرمز مشفّراً عبر Android Keystore، أوامر صوتية أولية، ردود صوتية، وفتح تطبيقات والكاميرا.
- اتصال Android بخدمة الذكاء عبر Bearer token منفصل؛ مفتاح OpenAI يبقى في Cloudflare.
- سجل آخر 12 رسالة مشفّر محلياً مع زر لمسحه.
- قارئ اختياري لإشعارات تطبيقات المراسلة بعد موافقة المستخدم، مع تجنّب النطق على شاشة القفل وتجاهل إشعارات رموز التحقق.
- تحضير SMS من أمر صوتي مع تأكيد المستخدم النهائي قبل الإرسال.
- إعلان رقم المكالمة الواردة عبر Android Call Screening بعد تفعيل الدور.
- مشاركة موقع طوارئ عبر رسالة جاهزة بعد حفظ رقم موثوق ومنح إذن الموقع؛ المستخدم يراجع الرسالة ويضغط إرسال.
- شاشة لطلب تعيين إميليا كمساعد النظام وإدارة الصلاحيات.
- GitHub Actions لبناء APK Android، وفحص Android Lint مع حفظ التقرير، و13 اختبار Worker آلي تشمل المصادقة، CORS preflight، حدود حجم الطلب، التحقق من المدخلات، عزل الذاكرة، نجاح رد الذكاء الاصطناعي، وأخطاء المزود. آخر بناء Debug APK على أحدث commit (a8eb2c5) نجح في 12 نوفمبر 2026، ونجحت اختبارات Worker الآلية على commit نفسه. التطبيق لم يُختبر بعد على هاتف Oppo.

**مهم:** هذه وظائف أولية في الكود وليست نسخة هاتف مجرّبة. الوضع المحلي المجاني يعمل دون Worker أو مفتاح API أو بطاقة بنكية. الردود المحلية محدودة وليست نموذج ذكاء اصطناعي عام. ربط خدمة سحابية خيار إضافي فقط وقد تكون لها حدود أو تكاليف. قارئ الإشعارات يحتاج موافقة صريحة. إرسال الرسائل ومشاركة الموقع يفتحان تطبيق الرسائل ولا يرسلان وحدهما. إعلان المتصل يعتمد على دعم الهاتف ويعلن الرقم حالياً، وليس اسماً من جهات الاتصال.

## شخصية إميليا

- حنونة وذكية وخفيفة الظل، وتتحدث بالدارجة الجزائرية الطبيعية.
- ترافق المستخدم دون ادعاء أنها إنسانة أو تشجيع التعلق الحصري بها.
- لا تختلق ذكريات أو معلومات ولا تدعي تنفيذ أوامر الهاتف دون تأكيد.
- تحفظ فقط المعلومات التي يختار المستخدم حفظها، مع إمكانية عرضها وحذفها وتصديرها.

## الاختبارات الآلية

من مجلد `worker` شغّل `npm test` لتشغيل اختبارات الخادم محلياً. GitHub Actions يشغّلها تلقائياً عند تعديل ملفات Worker أو فتح Pull Request. وتشغّل workflow منفصلة فحص Android Lint قبل بناء APK وتحفظ تقرير الفحص كـ artifact.

## ما ينقص قبل نسخة حقيقية مكتملة

1. تثبيت Debug APK واختباره على Oppo والتحقق من الأذونات والصوت.
2. بناء أحدث APK ونجاح Android Lint (تم التحقق منهما في 12 نوفمبر 2026؛ بقي تثبيت الملف وتجربته على الهاتف).
3. اختبار جلسة الصوت والمساعد الافتراضي على Oppo.
4. تطوير الردود المحلية المجانية دون ادعاء أنها نموذج لغوي كامل.
5. اختبار وظائف الصوت والذاكرة والأذونات على هاتف Oppo.
6. إضافة مزامنة اختيارية ونسخ احتياطي محلي.
7. تحسين اختيار جهة الاتصال بالاسم والتعرف على المتصل واختبار الطوارئ.
8. إصدار APK موقّع. ربط خدمة سحابية يبقى اختيارياً وليس شرطاً للتشغيل.


لا نعلن عن أي ميزة مكتملة إلا بعد بناء واختبار يمكن التحقق منه.
