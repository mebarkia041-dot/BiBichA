# 💜 BiBichA — بيبيشا

**الهدف النهائي:** مساعد ذكاء اصطناعي شخصي على Android، تتكلم معه بالصوت ويستجيب لك كمساعد هاتف، وليس مجرد صفحة ويب أو نافذة محادثة.

## الحالة الحالية
المستودع يحتوي حالياً على نموذج أولي ويب (واجهة عربية، سجل محادثة، ذاكرة محلية، وتجربة صوت عبر المتصفح) وخادم وسيط Cloudflare جاهز للربط مع OpenAI Responses API.

**هذا النموذج ليس بعدُ مساعد Android يعمل في الخلفية، ولا يستيقظ بكلمة تنبيه، ولا يتحكم بوظائف الهاتف.** كما أن الذكاء الاصطناعي الحقيقي غير مفعّل قبل نشر Worker وإضافة سر `OPENAI_API_KEY` في Cloudflare وربط عنوانه.

## الاتجاه المعتمد
راجع [خطة تحويل BiBichA إلى مساعد Android](ANDROID_ASSISTANT_PLAN.md). الهدف هو بناء تطبيق Android أصلي بصيغة APK، مع طبقة صوت ونظام Android، وخادم آمن للذكاء الاصطناعي والذاكرة.

## الموجود في النموذج الأولي
- واجهة محادثة عربية RTL.
- حفظ المحادثة والذاكرة محلياً على الهاتف.
- تصدير واسترجاع نسخة احتياطية.
- إدخال صوتي وقراءة الردود بحسب دعم المتصفح.
- PWA وتخزين ملفات الواجهة للعمل عند انقطاع الإنترنت.
- Cloudflare Worker backend مع اختبارات تلقائية.

## ما لم يكتمل بعد
- تطبيق Android أصلي APK.
- تشغيل كمساعد هاتف أو استدعاؤه من خارج واجهة المحادثة.
- تنبيه صوتي مستمر/كلمة إيقاظ؛ يحتاج خدمة Android أصلية واختبارات استهلاك البطارية والخصوصية.
- صوت طبيعي مستمر ثنائي الاتجاه.
- ذاكرة سحابية آمنة ومزامنة.
- ربط OpenAI الفعلي ونشر Worker.

## فحص الجودة
تشغّل اختبارات الخادم تلقائياً عبر GitHub Actions. نجاح الاختبارات لا يعني أن Worker أو مفتاح OpenAI منشوران.
