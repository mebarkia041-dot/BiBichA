# 💜 BiBichA — بيبيشا

**بيبيشا شخصية ذكاء اصطناعي ترافق المستخدم**: تتحدث معه طبيعياً، تفهم سياق كلامه، تتذكر ما يأذن بحفظه، وتساعده كمساعد هاتف. هي ذكاء اصطناعي واضح وليست إنسانة، وليست مجرد صفحة دردشة.

## الحالة الحقيقية الآن

المستودع يجمع بين:
- نموذج ويب تجريبي قديم للمحادثة.
- Cloudflare Worker وسيط لواجهة OpenAI Responses API، لكنه غير منشور/غير مربوط بمفتاح فعّال حسب آخر تحقق.
- مشروع Android أصلي بلغة Kotlin، مع خدمة VoiceInteraction أولية، تعرف على الأوامر الصوتية باللهجة العربية، ردود صوتية، ومحاولة فتح مجموعة تطبيقات معروفة.
- خدمة اختيارية لقراءة نصوص الإشعارات بصوت بعد أن يمنح المستخدم صلاحية Notification Access من إعدادات Android.
- شاشة أولية لطلب تعيين بيبيشا كمساعد النظام وفتح إعدادات صلاحية الإشعارات.
- GitHub Actions لاختبارات الخادم وبناء APK تجريبي.

**مهم:** الأوامر الصوتية الحالية محدودة بفتح بعض التطبيقات وردود صوتية بسيطة؛ ليست بعد محادثة ذكاء اصطناعي متصلة. قارئ الإشعارات يحتاج موافقة صريحة، ولا يرسل الرسائل نيابة عن المستخدم. هذه الميزات لم تُختبر بعد على هاتف Oppo فعلي. يجب نجاح بناء APK ثم اختباره على الجهاز. خدمة الذكاء لا تزال تحتاج نشر Worker ومصادقة آمنة للعميل الأصلي قبل ربط APK.

## شخصية بيبيشا

- حنونة وذكية وخفيفة الظل، وتتحدث بالدارجة الجزائرية الطبيعية.
- ترافق المستخدم دون ادعاء أنها إنسانة أو تشجيع التعلق الحصري بها.
- لا تختلق ذكريات أو معلومات ولا تدعي تنفيذ أوامر الهاتف دون تأكيد.
- تحفظ فقط المعلومات التي يختار المستخدم حفظها، مع إمكانية عرضها وحذفها وتصديرها.

## ما ينقص قبل نسخة حقيقية مكتملة

1. بناء APK والتحقق من تثبيته وتشغيله على Oppo.
2. توسيع جلسة الصوت لتصبح محادثة مستمرة مع الذكاء الاصطناعي، وتحسين الاستماع والمقاطعة وإدارة الصوت.
3. تفعيل تكامل المساعد الافتراضي فعلياً على الجهاز المستهدف.
4. نشر Worker وإضافة مفتاح API كسِرّ في Cloudflare.
5. إضافة مصادقة حقيقية لطلبات Android؛ CORS وحده ليس حماية ولا يصلح لإثبات هوية تطبيق أصلي.
6. ربط الذكاء واختبار محادثة حقيقية.
7. بناء ذاكرة شخصية محلية قابلة للإدارة، ثم مزامنة سحابية اختيارية وآمنة.
8. إضافة إجراءات الرسائل والمكالمات والطوارئ ومشاركة الموقع بعد تصميم صلاحيات واضحة وتأكيدات أمان.
9. اختبار الأذونات والبطارية والخصوصية، ثم إصدار APK موقّع.


لا نعلن عن أي ميزة مكتملة إلا بعد بناء واختبار يمكن التحقق منه.
